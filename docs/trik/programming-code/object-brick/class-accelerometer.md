# Класс «accelerometer»

Представляет [акселерометр](/docs/trik/programming-code/object-brick/#accelerometer) контроллера ТРИК.

| Метод                               | Описание                                                                                                                     |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| [read](#read) | Возвращает текущее показание сенсора в виде массива из трёх элементов, соответствующих показаниям сенсора по каждой из осей. |

| Сигнал                                    | Описание                                                       |
| ----------------------------------------- | -------------------------------------------------------------- |
| [newData](#newdata) | Сигнал, посылаемый сенсором, когда у него готовы новые данные. |

###### ​ {#read}
## read

Возвращает текущее показание сенсора в виде массива из трёх элементов, соответствующих показаниям сенсора по каждой из осей.

<Tabs>
<TabItem value={"python"} label={"Python"}>
```
brick.accelerometer().read()
```
</TabItem>

<TabItem value={"javascript"} label={"JavaScript"}>
```javascript
brick.accelerometer().read();
```
</TabItem>
</Tabs>

## newData

Сигнал, посылаемый сенсором, когда у него готовы новые данные.
