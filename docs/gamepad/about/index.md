# О TRIK Gamepad

TRIK Gamepad — пульт для управления программируемыми учебными роботами ТРИК, доступный в виде [приложений](/docs/gamepad/about/app/) для Android и iOS и [утилиты](/docs/gamepad/about/utility/) в TRIK Studio.

Для управления роботом с пульта необходимо написать [программу](/docs/gamepad/remote-control/) и запустить её на роботе.
