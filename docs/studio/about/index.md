# О TRIK Studio

**TRIK Studio** — бесплатная среда программирования роботов.

<div align="center"><img src="/gitbook/assets/trik_studio_logo_%26_text_right.png" alt="" /></div>

Она позволяет решать задачи как с помощью [визуального](/docs/studio/programming-visual/) программирования, так и [текстовых языков](/docs/studio/programming-code/).

</TabItem>

<TabItem value={"текстовое-программирование"} label={"Текстовое программирование"}>
![](/gitbook/assets/text.png)
</TabItem>
</Tabs>

Отличительной особенностью TRIK Studio является [интерактивный режим имитационного моделирования](/docs/studio/2d-model/). Чтобы научиться программировать, необязательно иметь конструктор.

![](/gitbook/assets/TRIK%20Studio%202D%20model.gif)

TRIK Studio — универсальное программное обеспечение для преподавания основ программирования. В ней предусмотрен переход [от диаграмм к текстовым языкам](/docs/studio/programming-code/#generation).

![](/gitbook/assets/generation.gif)

### Поддерживаемые платформы &#123;#platforms&#125;
TRIK Studio поддерживает 4 платформы:

* [Контроллер ТРИК](/docs/trik/about/).
* [LEGO EV3](/docs/ev3/about/).
* [LEGO NXT 2.0](/docs/nxt/about/).
* [Квадрокоптер Геоскан Пионер](/docs/pioneer/about/).

## Рекомендуемые системные требования

* Оперативная память: 4 ГБ или больше.
* Операционная система:
  * 64-разрядная Windows 10.
  * Ubuntu 16.04 и выше.
  * macOS 10.12 Sierra и выше.
